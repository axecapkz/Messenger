# Messenger for iOS

This is a simple iOS messaging application built using Swift and Xcode. The app allows users to sign up, log in, and send messages to each other in real-time. It integrates Firebase for authentication and real-time database features, and includes Facebook login functionality.

## Features

- **Real-Time Messaging**: Users can send and receive messages instantly.
- **User Authentication**: Supports both Firebase authentication and Facebook login.
- **Profile Management**: Users can create and update their profiles.
- **Multimedia Support**: Users can view photos and videos shared in the chat.
- **New Conversation Creation**: Users can start new conversations with other users.

## Getting Started

To run this project locally on your Mac:

1. **Clone the repository**:

   ```bash
   git clone https://github.com/axecapkz/Messenger.git

2. **Navigate to the project directory**:

   ```bash
   cd Messenger

3. **Open the project in Xcode**:

   ```bash
   open Messenger.xcodeproj

4. **Install CocoaPods dependencies**:

   ```bash
   pod install


5. **Run the project**:

- Open the .xcworkspace file.
- Select a simulator or a connected device in Xcode.
- Press Cmd + R or click the "Run" button to build and launch the app.

**Dependencies**

This project uses the following third-party libraries:

Firebase: For user authentication and real-time database features.
FBSDKLoginKit: For Facebook login integration.


**Requirements**

Xcode: Version 14.0 or later.
iOS: Supports iOS 15.0 and above.
CocoaPods: For managing dependencies.
Firebase: Firebase project setup for authentication and database.
